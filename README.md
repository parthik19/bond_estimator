# bond_estimator

Estimate the range of total returns a bond fund (e.g. SPHY, SCYB) is likely to deliver over the
next N years, from fact-sheet numbers plus your own default, recovery, rate and spread
assumptions, using a Monte Carlo simulation on top of a hand-checkable year-by-year engine.
